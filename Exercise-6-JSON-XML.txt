JSON و XML

JSON چیست؟
JSON (JavaScript Object Notation) یک فرمت متنی برای ذخیره و انتقال داده‌هاست که ساختاری ساده و قابل فهم برای انسان و ماشین دارد.

XML چیست؟
XML (Extensible Markup Language) یک زبان نشانه‌گذاری برای ذخیره و انتقال داده‌هاست که از تگ‌ها برای مشخص کردن ساختار اطلاعات استفاده می‌کند.

چه کاربردی دارند؟
از JSON و XML برای انتقال و ذخیره اطلاعات بین سیستم‌ها، برنامه‌ها و سرویس‌های مختلف استفاده می‌شود.
برای مثال، APIها می‌توانند اطلاعات را با استفاده از JSON یا XML ارسال و دریافت کنند.

چه تفاوت‌هایی با یکدیگر دارند؟
JSON معمولاً ساده‌تر و کم‌حجم‌تر است و در برنامه‌های وب و APIها کاربرد زیادی دارد.
XML ساختار تگ‌محور دارد و معمولاً حجم بیشتری نسبت به JSON ایجاد می‌کند.
JSON برای نمایش داده‌ها از ساختارهایی مانند Object و Array استفاده می‌کند، در حالی که XML از تگ‌ها استفاده می‌کند.


اطلاعات یک Student با JSON:

{
  "name": "Roya",
  "age": 19,
  "studentId": 140401,
  "major": "Multimedia"
}


اطلاعات یک Student با XML:

<Student>
    <Name>Roya</Name>
    <Age>19</Age>
    <StudentId>140401</StudentId>
    <Major>Multimedia</Major>
</Student>
